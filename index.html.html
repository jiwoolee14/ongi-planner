동기화와 데이터 관리

기기 간 자동 동기화는 클라우드 저장소 연결이 필요해요.

현재 상태: 이 기기에 저장
이 버전은 브라우저에 데이터를 저장합니다. 다른 기기와 자동으로 동기화되지는 않아요. 아래 백업/복원으로 기록을 옮길 수 있어요.

다른 앱에서 일정 가져오기

ICS/CSV 파일을 가져올 수 있어요. 단, TimeTree 자체 일정은 공식적으로 내보내기를 지원하지 않으므로 바로 가져오기는 어려워요. JSON 백업 파일은 전체 기록 복원용이에요.

자동 동기화 연결

여러 기기에서 안전하게 동기화하려면 로그인과 클라우드 데이터베이스가 필요합니다. 이 정적 파일만으로는 계정 동기화를 활성화할 수 없어요. 실제 배포 단계에서 Supabase 등의 저장소와 인증을 연결하도록 설계할 수 있어요.

개인 일기에는 민감한 내용이 담길 수 있어요. 공용 기기에서는 사용 후 로그아웃하고, 백업 파일도 안전한 곳에 보관해 주세요.
